Autofill

Open the quiz. Press Start. Check the answers.

Autofill reads every question on the page, gets an answer from Claude, Gemini or GPT, and fills it in. Each answer appears above its question so you can see it, ask why, and change it before you submit.

Every Moodle question type

  • Multiple choice
  • Select all that apply
  • True or false
  • Short answer
  • Numerical
  • Matching
  • Drop-down gaps
  • Essays
  • CodeRunner code
  • STACK maths
  • Google Forms

Code goes into the editor

CodeRunner answers are typed into Moodle's code editor, starting from the code the question already gives you.

Answers from your notes

Upload your course notes in the Notes tab. Questions that depend on your lecturer's material are answered from them.

Pay per question

One credit per question in Basic mode, two in Pro for harder questions. Buy credits with Paystack or PayPal.

Tell us when it's wrong

Press Bad on any answer and we get the question, so we can see what went wrong and fix it.

Learn by doing

Three more things we built.

LaceFi Academy

A beginner course in building websites, from your first HTML tag to JavaScript. Each lesson explains one idea with a real example, then you answer a short quiz and build it yourself. Assignments are checked automatically as you go.

  • 91 lessons: HTML, CSS and JavaScript
  • A quiz and an assignment in every lesson
  • Ends with a portfolio site, graded by a teacher
Open Academy

Sleuthbox

There has been a crime and the database knows who did it. Read the briefing, then query the evidence tables one SELECT at a time until the trail points to a name. More than 22 original cases, from a blackout at an observatory to who broke the living-room TV.

  • Real SQL in the browser
  • Easy, medium and hard cases
  • Walkthrough for first-timers
Play Sleuthbox

Number Duel

Two players, one room. Each of you locks in a secret number from 0 to 100, then you take turns guessing the other's. Every miss gets a higher or lower hint and costs 10 of your 100 points, so the fewer guesses you need, the more you keep.

  • Play a friend with a room ID
  • No sign-up
  • A hint after every guess
